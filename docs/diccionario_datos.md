# Diccionario de datos · Clínica veterinaria «Huellitas» (G02)

Base de datos: Oracle 26ai (FreeSQL). Las fechas se guardan en UTC y Django las muestra en hora de Chile (`America/Santiago`).

## DUENOS

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---|---|---|
| id | NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY (NOCACHE) | No | `pk_duenos` | Identificador del dueño |
| rut | VARCHAR2(12) | No | `uq_duenos_rut` | RUT chileno con puntos y guion (12.345.678-5) |
| nombre | VARCHAR2(100) | No | | Nombre completo |
| telefono | VARCHAR2(20) | No | | Teléfono de contacto (+56 9 ...) |
| email | VARCHAR2(120) | No | `uq_duenos_email`, `ck_duenos_email` (contiene @) | Correo electrónico |
| comuna | VARCHAR2(60) | No | | Comuna de residencia (se usa como filtro) |
| fecha_registro | TIMESTAMP | No | DEFAULT `SYS_EXTRACT_UTC(SYSTIMESTAMP)` | Fecha de registro en UTC |

## MASCOTAS

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---|---|---|
| id | NUMBER IDENTITY (NOCACHE) | No | `pk_mascotas` | Identificador de la mascota |
| dueno_id | NUMBER | No | `fk_mascotas_dueno` → duenos(id), índice `idx_mascotas_dueno` | Dueño de la mascota |
| nombre | VARCHAR2(60) | No | | Nombre de la mascota (no se repite para un mismo dueño, regla del caso de uso) |
| especie | VARCHAR2(20) | No | `ck_mascotas_especie` IN (perro, gato, ave, conejo, reptil, otro) | Especie |
| raza | VARCHAR2(60) | Sí | | Raza (opcional) |
| sexo | VARCHAR2(1) | No | `ck_mascotas_sexo` IN ('M','H') | Macho o hembra |
| fecha_nacimiento | DATE | Sí | | Fecha de nacimiento (no puede ser futura, validado en el serializer) |

## SERVICIOS

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---|---|---|
| id | NUMBER IDENTITY (NOCACHE) | No | `pk_servicios` | Identificador del servicio |
| codigo | VARCHAR2(10) | No | `uq_servicios_codigo` | Código con formato AAA-00 (ej: VAC-01) |
| nombre | VARCHAR2(100) | No | `uq_servicios_nombre` | Nombre del servicio |
| descripcion | CLOB | Sí | | Descripción larga |
| precio | NUMBER(10,2) | No | `ck_servicios_precio` ≥ 0 | Precio vigente en pesos |
| activo | NUMBER(1) | No | `ck_servicios_activo` IN (0,1), DEFAULT 1 | 1 = se ofrece, 0 = suspendido (R2) |

## ATENCIONES (entidad principal)

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---|---|---|
| id | NUMBER IDENTITY (NOCACHE) | No | `pk_atenciones` | Identificador de la atención |
| mascota_id | NUMBER | No | `fk_atenciones_mascota` → mascotas(id), índice `idx_atenciones_mascota` | Mascota atendida |
| fecha | TIMESTAMP | No | índice `idx_atenciones_fecha` | Fecha y hora de la atención, en UTC |
| motivo | VARCHAR2(200) | No | | Motivo de la consulta |
| total | NUMBER(10,2) | No | `ck_atenciones_total` ≥ 0, DEFAULT 0 | Suma del detalle (R2: siempre recalculado) |
| estado | VARCHAR2(12) | No | `ck_atenciones_estado` IN (agendada, realizada, pagada, cancelada) | Estado actual |
| fecha_creacion | TIMESTAMP | No | DEFAULT `SYS_EXTRACT_UTC(SYSTIMESTAMP)` | Momento en que se agendó |

## DETALLE_ATENCION (detalle, clave compuesta)

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---|---|---|
| atencion_id | NUMBER | No | parte de `pk_detalle_atencion`, `fk_detalle_atencion` → atenciones(id) ON DELETE CASCADE | Atención |
| servicio_id | NUMBER | No | parte de `pk_detalle_atencion`, `fk_detalle_servicio` → servicios(id) | Servicio aplicado |
| cantidad | NUMBER(5) | No | `ck_detatencion_cantidad` > 0 | Unidades del servicio |
| precio_unitario | NUMBER(10,2) | No | `ck_detatencion_precio` ≥ 0 | Precio del servicio al momento de agendar |
| subtotal | NUMBER(12,2) | — | GENERATED ALWAYS AS (cantidad * precio_unitario) VIRTUAL | Columna virtual calculada por Oracle |
